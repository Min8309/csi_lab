## 12. 결측 기호를 0으로 바꾸지 않습니다

숫자 파싱의 첫 단계에서 “자료 없음”의 의미를 보존합니다.

“-”, 빈칸, NaN은 결측으로 보존
쉼표가 있는 숫자는 float로 변환
관측되지 않은 값과 실제 0건을 구분

```python
def clean_number(value):
    if pd.isna(value):
        return pd.NA
    value = str(value).strip()
    if value in ["-", "", "nan", "NaN"]:
        return pd.NA
    value = value.replace(",", "")
    try:
        return float(value)
    except ValueError:
        return pd.NA
```

## 15. 공표 검거율과 계산 검거율을 구분합니다

df["calculated_clearance_rate"] = np.where(
    (df["occurrence_count"].notna())
    & (df["arrest_count"].notna())
    & (df["occurrence_count"] > 0),
    df["arrest_count"]
    / df["occurrence_count"]

## 18. 긴 시계열에도 관측 완성도 기준을 둡니다

연도 수와 커버리지를 함께 보아 분석 등급을 나눕니다.

coverage_rate=year_count/year_span×100입니다. 30Y 30년·90%, 20Y 20년·80%, 10Y 10년·70% 기준을 사용합니다. 33년을 관측했어도 법·집계 기준이 기간 내내 동일하다고 보장하지는 않습니다.

```python
def make_time_grade(row):
    years = row["year_count"]
    coverage = row["coverage_rate"]
    if years >= 30 and coverage >= 90:
        return "30Y"
    if years >= 20 and coverage >= 80:
        return "20Y"
    if years >= 10 and coverage >= 70:
        return "10Y"
    return "SHORT"
```
